# AutoExpress — ดาวน์โหลดและอัปเดต

แหล่งแจกโปรแกรม Windows และข้อมูลอัปเดตที่ลงนามสำหรับทีม AutoExpress

## เริ่มใช้บนเครื่องใหม่

[ดาวน์โหลดชุดสำหรับเครื่องใหม่](https://github.com/narongkron1-g/autoexpress-releases/releases/latest/download/AutoExpress-NewMachine.zip) หรือดู [รุ่นล่าสุด](https://github.com/narongkron1-g/autoexpress-releases/releases/latest)

แตก ZIP ลงโฟลเดอร์ที่มีสิทธิ์เขียน แล้วเปิด AutoExpress.exe ไม่ต้องติดตั้ง Python โปรแกรมมีตัวช่วยตั้งค่า 6 ขั้นตอนและคู่มือภาษาไทยรวมในชุด

เตรียม Express ของบริษัท ขอชุดตั้งค่าทีม (SKU ร้าน บันเดิล ลายเซ็น) จากผู้ดูแลภายในบริษัท หากสร้าง PDF ให้ติดตั้ง doPDF 11 และหากส่งอีเมลให้ใช้บัญชี Google/Gmail กับ App Password ของผู้ส่งเอง ตั้ง Shopee/Chrome เฉพาะเมื่อต้องใช้

## ผู้ใช้เดิมและการอัปเดต

รับรุ่นที่มีระบบอัปเดตครั้งแรกหนึ่งครั้ง จากนั้นกด **ตรวจสอบอัปเดต** ในโปรแกรม เลือก **อัปเดตและเปิดโปรแกรมใหม่** เมื่อพร้อม โปรแกรมตรวจลายเซ็นและ SHA-256 ก่อนติดตั้ง เก็บค่าตั้งค่าและข้อมูลแต่ละเครื่อง พร้อมรักษาไฟล์ขั้นตอนที่แก้เอง

หากนำชุดแรกไปใส่โฟลเดอร์เดิม ให้ปิดโปรแกรมก่อนและรักษาไฟล์ขั้นตอนที่ปรับเองไว้ อ่านคู่มือที่มากับชุดก่อนเริ่มงาน

## สิ่งที่อยู่ใน repository นี้

เฉพาะไฟล์โปรแกรม ชุดขั้นตอนมาตรฐาน คู่มือใช้งาน และข้อมูล release ที่ลงนาม ไม่มีซอร์สโปรเจกต์ บัญชีอีเมล รหัสผ่าน ลายเซ็นจริง ข้อมูลลูกค้า SKU ของบริษัท ฉบับร่าง ประวัติ หรือ PDF จากเครื่องผู้จัดทำ

ชุดตั้งค่าทีมและกุญแจลงนาม private ต้องเก็บเป็นส่วนตัว ห้ามอัปโหลดใน repository นี้
